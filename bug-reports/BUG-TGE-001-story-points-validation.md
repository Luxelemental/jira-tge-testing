# BUG-TGE-001: Table Grid Editor принимает невалидные данные в числовое поле и зависает

## 📋 Информация
- **ID:** BUG-TGE-001
- **Severity (Серьезность):** High
- **Priority (Приоритет):** High
- **Статус:** Open
- **Автор:** Luxelemental

## 📝 Описание проблемы
При инлайн-редактировании числового поля "Story Points" через плагин Table Grid Editor, если ввести буквенные символы вместо чисел, система не валидирует ввод, сохраняет мусорные данные в базу и перестает отвечать на действия пользователя в таблице (зависает UI).

## 👣 Шаги воспроизведения
1. Авторизоваться в Jira под пользователем с правами *Edit Issues* (например, `User_Admin`).
2. Открыть Issue Navigator (меню *Filters* → *Advanced issue search*).
3. Нажать кнопку "Table Grid Editor" в панели инструментов.
4. Найти в таблице задачу `TEST-104` (у которой поле Story Points = `5`).
5. Кликнуть один раз по ячейке в колонке "Story Points".
6. Ввести значение: `abc`.
7. Нажать клавишу `Enter`.

## ✅ Ожидаемый результат
1. Система отклоняет ввод невалидных данных.
2. Появляется красная подсветка ячейки или всплывающая ошибка: *"Invalid number. Story Points must be a positive integer"*.
3. Значение в ячейке остается прежним (`5`).
4. Таблица продолжает работать нормально.

## ❌ Фактический результат
1. Система НЕ отклонила ввод — значение `abc` было принято.
2. Ошибка валидации НЕ появилась.
3. Таблица перестала реагировать на клики (зависла).
4. После обновления страницы (F5) в поле Story Points задачи `TEST-104` отображается значение `abc`.

## 🖥️ Окружение (Environment)
- **Jira:** Cloud (версия 9.4.2)
- **Плагин:** Table Grid Editor (версия 3.2.1)
- **Браузер:** Google Chrome 120.0.6099.130 (64-bit)
- **ОС:** Windows 11 (версия 22H2)

## 💡 Временное решение (Workaround)
Пользователю необходимо обновить страницу (F5), открыть задачу `TEST-104` в стандартном режиме Jira и вручную очистить поле Story Points.
