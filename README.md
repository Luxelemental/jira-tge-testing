# 🧪 Тестирование плагина Table Grid Editor для Jira

## 📋 О проекте

Этот репозиторий содержит полную тестовую документацию для плагина **Table Grid Editor (TGE)** — инструмента для отображения и редактирования задач Jira в табличном виде.

## 🛠 Примененные техники тест-дизайна

### Граничные значения (Boundary Value Analysis)
Для поля Story Points (целые положительные числа):
- ✅ `1` — нижняя граница (валидное)
- ✅ `0` — ниже границы (невалидное)
- ✅ `-5` — отрицательное число (невалидное)

### Классы эквивалентности (Equivalence Partitioning)
- ✅ Валидный класс: любое целое положительное число (например, `5`)
- ✅ Невалидный класс 1: буквы (`abc`)
- ✅ Невалидный класс 2: отрицательные числа (`-5`)
- ✅ Невалидный класс 3: дробные числа (`3.14`)
