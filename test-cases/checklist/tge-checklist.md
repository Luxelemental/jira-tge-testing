# Чек-лист тестирования Table Grid Editor

## 🎨 UI & Display (Отображение и интерфейс)
- [ ] Кнопка открытия TGE отображается в Issue Navigator.
- [ ] Таблица загружает и отображает колонки согласно конфигурации.
- [ ] Работает сортировка по клику на заголовок колонки (A-Z, Z-A).
- [ ] Работает фильтрация и поиск внутри таблицы.

## ✏️ Inline Editing (Инлайн-редактирование)
- [ ] Можно отредактировать текстовое поле (Summary).
- [ ] Можно изменить выпадающий список (Priority, Status).
- [ ] Изменения сохраняются при нажатии `Enter` или клике вне ячейки.
- [ ] Изменения отменяются при нажатии `Esc`.

## 🔄 Bulk Edit (Массовое редактирование)
- [ ] Можно выделить несколько строк через чекбоксы слева.
- [ ] Можно изменить значение (например, Assignee) для всех выделенных строк одновременно.
- [ ] История изменений (History) в каждой задаче корректно обновляется.

## 🔒 Permissions & Validation (Права доступа и валидация)
- [ ] Пользователь без прав *Edit Issues* видит таблицу в режиме read-only (ячейки не редактируются).
- [ ] Нельзя ввести невалидные данные (текст в числовое поле Story Points).
- [ ] При вводе невалидных данных появляется понятная ошибка, таблица не зависает.
