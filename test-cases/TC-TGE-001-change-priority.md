# TC-TGE-001: Успешное изменение Priority через инлайн-редактирование

## 📋 Информация
- **ID:** TC-TGE-001
- **Приоритет:** High
- **Тип:** Позитивный
- **Теги:** `inline-edit`, `priority`, `positive`

## 🎯 Описание
Проверка базовой способности плагина менять приоритет задачи прямо в таблице без открытия карточки задачи.

## 🔧 Предусловия
1. Пользователь `User_Admin` авторизован в Jira (имеет право *Edit Issues*).
2. Открыт Issue Navigator, включен режим отображения Table Grid Editor.
3. В таблице присутствует задача `TEST-101` с текущим приоритетом "Medium".

## 👣 Шаги выполнения

| № | Действие | Ожидаемый результат |
|:--|:---------|:--------------------|
| 1 | Найти в таблице строку с задачей `TEST-101`. | Строка отображается, в колонке Priority видно значение "Medium". |
| 2 | Кликнуть один раз по ячейке в колонке "Priority" у этой задачи. | Ячейка переходит в режим редактирования, появляется выпадающий список. |
| 3 | В выпадающем списке выбрать значение "High". | Значение "High" выбрано в списке. |
| 4 | Нажать клавишу `Enter` (или кликнуть вне ячейки). | Изменения сохраняются. Появляется системное уведомление (toast) об успешном сохранении. |

## ✅ Постусловия
1. В стандартной карточке задачи `TEST-101` поле Priority равно "High".
2. На вкладке *History* задачи появилась запись: *"Priority changed from Medium to High by User_Admin"*.
