# TC-TGE-004: Ввод невалидных данных в числовое поле Story Points

## 📋 Информация
- **ID:** TC-TGE-004
- **Приоритет:** Medium
- **Тип:** Негативный
- **Теги:** `validation`, `boundary-values`, `negative`

## 🎯 Описание
Проверка валидации ввода данных в числовое поле с использованием техник граничных значений и классов эквивалентности.

## 🔧 Предусловия
1. Пользователь `User_Admin` авторизован в Jira.
2. В конфигурации TGE включено отображение поля "Story Points".
3. Задача `TEST-104` имеет текущее значение Story Points = `5`.

## 👣 Шаги выполнения

| № | Действие | Ожидаемый результат |
|:--|:---------|:--------------------|
| 1 | Кликнуть по ячейке "Story Points" у задачи `TEST-104`. | Ячейка переходит в режим редактирования, появляется текстовый курсор. |
| 2 | Ввести буквенное значение `abc` и нажать `Enter`. | Система отклоняет ввод. Появляется ошибка валидации. Значение остается `5`. |
| 3 | Ввести отрицательное число `-5` и нажать `Enter`. | Система отклоняет ввод (нижняя граница нарушена). Значение остается `5`. |
| 4 | Ввести дробное число `3.14` и нажать `Enter`. | Система отклоняет ввод (поле принимает только целые числа). Значение остается `5`. |

## ✅ Постусловия
- Таблица не зависает и продолжает реагировать на действия пользователя.
- В истории задачи `TEST-104` отсутствуют записи об изменении поля Story Points.
